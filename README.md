# Amara Shiloh Iku — Portfolio

Live site: https://amaraiku.github.io

## How to edit (all in your browser on GitHub)

| To change… | Open this file |
|---|---|
| Projects (add, remove, reorder) | `_data/projects.yml` |
| Your headline, About text, skills, tools, education, email, links | `_data/profile.yml` |
| Your photo | `assets/photo.jpg` |

1. Open the file on GitHub and click the **pencil icon** (Edit).
2. Make your change. Follow the notes at the top of the file.
3. Click **Commit changes**, then **Commit changes** again.
4. Wait 1–2 minutes, then refresh your site.

**Add a project:** in `_data/projects.yml`, copy an existing block (from `- title:` to just before the next `- title:`), paste it at the bottom, and change the words.

**Change your photo:** open the `assets` folder → **Add file → Upload files** → upload a square photo named exactly `photo.jpg` → Commit.

**If the site stops updating:** a spacing or colon mistake is the usual cause. Open the **Actions** tab; a red ✗ means the last edit broke. Undo it or check that text containing a colon is wrapped in "quotes".
